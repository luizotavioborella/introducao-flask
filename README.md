# 🌐 Introduction to Flask

A collection of introductory activities developed with Python and Flask to practice the basic concepts of web development with backend integration.

This project was created during the Systems Development course at SENAI as an introduction to Flask, routes, templates and dynamic content.

## ✨ Features

- Basic Flask routes
- Dynamic values displayed in HTML templates
- Lists rendered with Jinja
- Loops using `for`
- Conditional structures using `if` and `else`
- Multiple HTML pages
- Basic CSS integration

## 📄 Pages

### 👋 Greeting
Displays a dynamic name sent from Python to an HTML template.

### 👥 Names
Displays a list of names using a Jinja loop.

### 🎓 Students
Displays a list of students and applies a condition to highlight a specific name.

### 👤 Profile
Practices conditional rendering based on a login status.
